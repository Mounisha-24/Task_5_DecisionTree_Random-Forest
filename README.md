# Breast Cancer Prediction Using Machine Learning

## Project Overview

This project uses machine learning classification algorithms to predict whether a breast tumor is **Benign** or **Malignant** based on tumor-related features.

The main objective is to build and evaluate machine learning models using the Breast Cancer dataset and compare their performance.

## Algorithms Used

* Decision Tree Classifier
* Random Forest Classifier

## Project Objectives

* Understand and preprocess the breast cancer dataset.
* Train a Decision Tree classification model.
* Visualize the Decision Tree.
* Analyze overfitting and control tree depth.
* Train a Random Forest classification model.
* Compare the performance of both models.
* Identify important features using feature importance.
* Evaluate model performance using cross-validation.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Dataset

The project uses a Breast Cancer dataset containing tumor-related measurements.

The target variable classifies tumors into:

* **Benign (B):** Non-cancerous tumor.
* **Malignant (M):** Cancerous tumor.

## Project Workflow

1. Import the required Python libraries.
2. Load and explore the dataset.
3. Clean and preprocess the data.
4. Split the dataset into training and testing sets.
5. Train a Decision Tree model.
6. Visualize the Decision Tree.
7. Analyze overfitting by adjusting tree depth.
8. Train a Random Forest model.
9. Compare model accuracy.
10. Analyze feature importance.
11. Perform 5-fold cross-validation.

## Model Evaluation

The models are evaluated using:

* Accuracy Score
* Confusion Matrix
* Classification Report
* Precision
* Recall
* F1-Score
* 5-Fold Cross-Validation
